# FUTURE_CS_01 — Vulnerability Assessment Report

## Overview
This project is Task 1 of the Future Interns Cyber Security Internship. 
It involves performing a vulnerability assessment on a live web application 
(OWASP Juice Shop demo instance) to identify common security weaknesses, 
classify their risk level, and recommend remediation steps.

## Tools Used
- Nmap – network/service scanning
- OWASP ZAP (Passive Scan) – web vulnerability detection
- Browser DevTools – manual header/cookie inspection
- Canva – report design

## What This Repo Contains
- `Vulnerability_Assessment_Report.pdf` – full report with findings, risk 
  ratings, and remediation steps
- Scan output screenshots (Nmap, ZAP alerts)

## Key Skills Demonstrated
- Vulnerability identification and analysis
- Risk classification (Low / Medium / High)
- Security reporting in business-friendly language
- Client-ready remediation recommendations
